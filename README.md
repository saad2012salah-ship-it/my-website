# منتدى مساحة

منتدى عربي/إنجليزي يعمل بخادم Python. يحفظ البيانات افتراضيًا في SQLite محلية، ويمكنه استخدام PostgreSQL عند وضع رابط اتصال في `MASAHA_DB` أو `DATABASE_URL`. يشمل الحسابات والملفات الشخصية وصور الغلاف، إعدادات البريد وكلمة المرور، الوسوم والبحث، المواضيع والردود، اختيار أفضل إجابة، مسودات تلقائية، رسائل خاصة، الإعجابات والمحفوظات والإشعارات، الإبلاغ وسجل إجراءات الإشراف وحظر الحسابات. الموقع قابل للتثبيت كتطبيق ويب على الأجهزة والمتصفحات الداعمة، ويخزن ملفات الواجهة للعمل دون اتصال؛ ميزات الحساب تحتاج اتصال الخادم. لا يحتاج مكتبات خارجية مع SQLite؛ استخدام PostgreSQL يتطلب تثبيت `requirements.txt`.

## تشغيله على جهازك

1. افتح مجلد `my-website` في الطرفية.
2. شغّل: `python3 server.py`
3. افتح `http://127.0.0.1:10000` في المتصفح.

التسجيل وتسجيل الدخول لا يتطلبان رمز تحقق بالبريد. يمكن لصاحب الحساب البدء مباشرة بعد التسجيل. لذلك لا يتحقق الموقع من ملكية البريد، وقد لا يتمكن المستخدم من استعادة الحساب إذا كتب بريدًا غير صحيح. إعداد SMTP مطلوب فقط لإرسال روابط استعادة كلمة المرور ونسخ البلاغات للمدير.

استعادة كلمة المرور: اكتب البريد في «نسيت كلمة المرور؟»، ثم افتح الرابط الذي يُرسل للبريد أو يظهر في نافذة الخادم إذا لم تضبط SMTP.

ينشئ الخادم نسخة من قاعدة البيانات عند كل تشغيل، ثم نسخة يومية، ويحتفظ بآخر 7 نسخ داخل مجلد `backups/`. للاستعادة محليًا: أوقف الخادم بـ`Ctrl+C`، انسخ ملف النسخة المطلوبة من `backups/` إلى مسار قاعدة البيانات المحدد في `MASAHA_DB` (أو إلى `masaha.sqlite3` بجانب `server.py` إذا لم تحدد المتغير)، ثم شغّل الخادم مجددًا. استعادة نسخة قديمة تعيد البيانات إلى وقت إنشاء تلك النسخة.

أول حساب تنشئه مدير إذا شغلت الخادم مع متغير `ADMIN_EMAIL` يطابق بريده. الحسابات وكلمات المرور المشفّرة والجلسات تُحفظ تلقائيًا في قاعدة البيانات بعد كل طلب. افتراضيًا يستخدم الخادم `masaha.sqlite3` بجانب `server.py` مع وضع WAL. لتشغيل PostgreSQL، ثبّت المتطلبات وضع رابط الاتصال في `MASAHA_DB` (أو `DATABASE_URL`). قاعدة SQLite الموجودة لا تُنقل تلقائيًا إلى PostgreSQL؛ اترك الإعداد فارغًا للاحتفاظ بها. في SQLite استخدم قرصًا دائمًا، لا مجلدًا مؤقتًا أو قرصًا يُحذف عند إعادة النشر. إذا تعذّر الاتصال بالخادم (مثل فتح `index.html` مباشرة)، يحفظ الموقع المواضيع والردود محليًا في المتصفح نفسه. هذا الحفظ لا ينتقل إلى جهاز آخر أو متصفح آخر، وقد يُمسح عند حذف بيانات المتصفح؛ للحفظ المشترك بين الزوار شغّل خادم Python واتصل به.

تصل البلاغات إلى قسم «البلاغات» المستقل الذي يظهر للمدير في شريط التنقل، مع تحديث دوري وتنبيه عند وصول بلاغ جديد. شغّل الخادم مع `ADMIN_EMAIL` مضبوطًا على بريد حسابك، ثم سجّل الدخول بهذا البريد. إذا أعددت SMTP، يرسل الخادم نسخة من كل بلاغ إلى بريد المدير. أضيفت قائمة تنقل للموبايل وتحسينات تركيز ولوحة مفاتيح ودعم تقليل الحركة. يستطيع صاحب الموضوع والمدير تعديله أو حذفه، وكذلك صاحب الرد. يقدر المدير استعراض البلاغات المفتوحة والمغلقة من قسم البلاغات. يستطيع العضو تغيير البريد وكلمة المرور من إعدادات الحساب، وإضافة صورة غلاف ووسوم للنقاشات. تعرض قائمة النقاشات 20 موضوعًا في كل مرة مع زر «عرض المزيد». يحدّ الخادم من النشر إلى 5 مواضيع و20 ردًا و10 بلاغات لكل حساب خلال ساعة، ويرفض تكرار الموضوع نفسه من الحساب خلال يوم.

يستطيع المدير إضافة أقسام مخصصة باسم عربي وإنجليزي ووصف، وحذف القسم المخصص إذا لم يحتوِ نقاشات؛ الأقسام الأساسية محمية. تعرض الأقسام عدد نقاشاتها، وتظهر تلقائيًا في النشر والتصفية. يمكن البحث والترتيب داخل المحفوظات، وتصفية البلاغات حسب النوع والحالة والبحث في تفاصيلها. تعرض صفحة العضو عدد مواضيعه وردوده وقائمة بردوده الأخيرة.

تتضمن الواجهة أيضًا متابعة الأعضاء والأقسام مع موجز للمشاركات الجديدة، استطلاعات داخل النقاشات، تثبيت المواضيع للمدير، ونقاطًا وشارات محسوبة من نشاط الأعضاء. تتحدث الرسائل كل 4 ثوانٍ والإشعارات والرسائل غير المقروءة كل 10 ثوانٍ أثناء بقاء الموقع مفتوحًا. لا يتطلب المشروع حالياً خدمة Push من المتصفح. يستطيع المدير مشاهدة إحصاءات المجتمع. يمكن للأعضاء استخدام الوضع الليلي وزر المعاينة وتنسيق النص بالغامق والمائل والشفرة، كما توجد صفحة للمساعدة وقواعد المجتمع والأسئلة الشائعة.

## نشره على Google Cloud

هذا المشروع يحتاج خادمًا دائمًا؛ ارفع الملفات إلى **Compute Engine VM**، وليس Google Sites. استخدم قرص VM دائمًا لتظل قاعدة SQLite موجودة بعد إعادة التشغيل، وخذ نسخًا احتياطية منها. إنشاء VM أو عنوان IP أو استخدام الشبكة قد يكلّف مالًا حسب إعدادات مشروعك؛ راجع التكلفة في Google Cloud قبل إنشائه.

### 1. أنشئ VM

- أنشئ مشروعًا في Google Cloud وفعّل Compute Engine والفوترة.
- أنشئ VM بنظام Debian، وأضف قواعد جدار ناري تسمح بـ HTTP وHTTPS.
- احجز عنوان IP خارجيًا ثابتًا، واربطه باسم نطاق تملكه عبر سجل DNS من نوع A.
- اتصل بالـVM من زر SSH في صفحة Compute Engine.

### 2. ارفع ملفات المنتدى

من جهازك، ثبّت Google Cloud CLI وسجّل الدخول واختر المشروع، ثم نفّذ من مجلد المشروع (استبدل `VM_NAME` و`ZONE`):

```sh
gcloud compute ssh VM_NAME --zone=ZONE --command="mkdir -p ~/masaha"
gcloud compute scp server.py app.js index.html style.css manifest.json sw.js icon.svg requirements.txt VM_NAME:masaha/ --zone=ZONE
```

ارجع إلى SSH داخل الـVM وثبّت الخادم والوكيل وعميل HTTPS:

```sh
sudo apt update
sudo apt install -y python3 python3-venv nginx certbot python3-certbot-nginx
```

### 3. شغّل Python كخدمة

في SSH، اعرف اسم مستخدمك بـ`whoami`، واستبدل `VMUSER` و`your@email.com` في المثال. اجعل `ADMIN_EMAIL` البريد الذي ستسجّل به حساب المدير:

```sh
sudo nano /etc/systemd/system/masaha.service
```

ضع هذا المحتوى:

```ini
[Unit]
Description=Masaha Forum
After=network.target

[Service]
User=VMUSER
WorkingDirectory=/home/VMUSER/masaha
ExecStart=/home/VMUSER/masaha/.venv/bin/python /home/VMUSER/masaha/server.py
Restart=always
Environment=HOST=127.0.0.1
Environment=PORT=10000
Environment=ADMIN_EMAIL=your@email.com
Environment=COOKIE_SECURE=1
Environment=SITE_URL=https://forum.example.com
EnvironmentFile=-/etc/masaha.env

[Install]
WantedBy=multi-user.target
```

بدّل `forum.example.com` باسم نطاقك. أنشئ البيئة وثبّت المتطلبات (مطلوبة إذا استخدمت PostgreSQL):

```sh
cd /home/VMUSER/masaha
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

اترك `MASAHA_DB` غير مضبوط لاستخدام SQLite بجانب `server.py`. لاستخدام PostgreSQL، أضف رابط الاتصال إلى `/etc/masaha.env` باسم `MASAHA_DB=postgresql://...`؛ خذ نسخة احتياطية قبل تبديل قاعدة البيانات لأن حسابات SQLite لا تُنقل تلقائيًا. نسخ PostgreSQL الاحتياطية تحتاج أداة `pg_dump` على الخادم. ثم فعّل الخدمة:

لإرسال روابط استعادة كلمة المرور ونسخ البلاغات للمدير، أنشئ ملف إعداد SMTP:

```sh
sudo nano /etc/masaha.env
```

إذا كان الإرسال من Gmail، فعّل التحقق بخطوتين وأنشئ كلمة مرور تطبيق لحساب الإرسال؛ Gmail لا يقبل كلمة مرور الحساب العادية لهذا النوع من تسجيل الدخول. كلمة مرور التطبيق متاحة للحسابات التي فعّلت التحقق بخطوتين، وقد لا تظهر لبعض أنواع الحسابات. [تعليمات Google الرسمية](https://support.google.com/accounts/answer/185833). أدخل بيانات المُرسِل في `/etc/masaha.env` (لا تضع كلمة المرور في ملفات المشروع):

```ini
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-sender@gmail.com
SMTP_PASSWORD=your-16-character-app-password
SMTP_FROM=your-sender@gmail.com
```

ثم احمِ الملف:

```sh
sudo chmod 600 /etc/masaha.env
sudo systemctl daemon-reload
sudo systemctl enable --now masaha
```

إذا كانت الخدمة تعمل من قبل، أعد تشغيلها بعد تعديل الإعدادات: `sudo systemctl restart masaha`. افحص أخطاء SMTP من سجل الخادم باستخدام `sudo journalctl -u masaha -n 100 --no-pager`.

### 4. اربط النطاق وHTTPS

أنشئ إعداد Nginx:

```sh
sudo nano /etc/nginx/sites-available/masaha
```

ضع الإعداد التالي مع استبدال النطاق:

```nginx
server {
    listen 80;
    server_name forum.example.com;
    location / {
        proxy_pass http://127.0.0.1:10000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

فعّل الموقع وأصدر شهادة HTTPS:

```sh
sudo ln -s /etc/nginx/sites-available/masaha /etc/nginx/sites-enabled/masaha
sudo nginx -t
sudo systemctl reload nginx
sudo certbot --nginx -d forum.example.com
```

أكمل خطوات Certbot، ثم أعد تشغيل المنتدى حتى يقرأ إعدادات النطاق:

```sh
sudo systemctl restart masaha
```

سجّل حساب المدير باستخدام البريد المحدد في `ADMIN_EMAIL`. النسخ اليومية تحفظ على القرص نفسه. لرفع نسخة تلقائيًا إلى Google Cloud Storage، جهّز bucket وخدمة `gcloud` على الـVM وامنح هوية الـVM صلاحية إنشاء كائنات فيه، ثم أضف إلى `/etc/masaha.env` السطر `MASAHA_BACKUP_BUCKET=gs://اسم-bucket/masaha` وبعدها أعد تشغيل الخدمة. يرفع الخادم كل نسخة جديدة إلى هذا المسار؛ تحقق من سجلات الخدمة لرسالة نجاح الرفع.

### 5. أضفه إلى بحث Google

بعد فتح موقعك عبر HTTPS، أضف النطاق إلى Google Search Console، ثم أرسل `https://forum.example.com/sitemap.xml`. أداة خريطة الموقع تساعد Google على اكتشاف الصفحات، لكنها لا تضمن ظهورها أو موعد ظهورها في النتائج.

## ملاحظات

- كل النصوص والمواضيع والبلاغات عامة للزوار، باستثناء البريد الإلكتروني.
- الحسابات والمحتوى مشتركة بين الزوار عند تشغيل الخادم المنشور.
- إدارة البلاغات تظهر للحساب المرتبط ببريد `ADMIN_EMAIL`.
- لا يحتاج التسجيل إلى البريد للتحقق؛ SMTP يُستخدم لاستعادة كلمة المرور وإشعارات البلاغات فقط.
- حدود النشر محفوظة في SQLite وتبقى بعد إعادة تشغيل الخادم. النسخ خارج الخادم اختيارية وتتطلب إعداد Google Cloud Storage كما سبق.
